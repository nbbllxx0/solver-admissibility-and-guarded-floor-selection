# Analysis tables

Minimal research-data deposit for the article *When a positive SIMP density floor is
not enough: solver admissibility and guarded floor selection in matrix-free 3D
topology optimization*.

These 22 CSV files are the per-state and per-run analysis tables from which every
figure and every table in the article is computed. They are the reduced outputs of
the experiment drivers in this repository, not raw solver logs: one row per state,
per trajectory step, or per configuration, with the residuals, iteration counts,
acceptance decisions, compliance values, and wall times that the article reports.

## Scope

Included: exactly the tables that a figure or table in the article is derived from.

Not included: the eight stored optimized-density fields used by the transfer study
and the SI gallery. Those are inputs carried over from prior work rather than
results of this study, and the article characterizes them in its
optimized-source-metadata table instead of redistributing them.

Everything except the transfer study and the hardware-specific wall-time tables can
be regenerated from the code in this repository alone; see the top-level README for
the environment files and the per-figure commands.

## Manifest

`MANIFEST.csv` lists every file with four columns:

| Column | Meaning |
| --- | --- |
| `file` | file name in this directory |
| `bytes` | size on disk |
| `sha256` | SHA-256 of the file contents |
| `supports` | the section, table, or figure of the article it feeds |

To verify integrity:

```
sha256sum -c <(awk -F, 'NR>1{print $3"  "$1}' MANIFEST.csv)
```

## Naming

File names are the source directory and the source file joined by a double
underscore, so `review_experiment_summary__heldout_false_keeps.csv` was produced as
`heldout_false_keeps.csv` by the `review_experiment_summary` stage. This keeps the
deposit flat while preserving which stage emitted each table.

## Notes on the contents

- Residuals are relative: `||f - Ku|| / ||f||`, FP64 throughout.
- Where a table carries both a projected and a recomputed residual, the projected
  value is the quantity the solver stopped on and the recomputed value is the
  quantity the article's acceptance test uses. The two disagreeing is the subject of
  the article, not an error in the table.
- Seeds identify pseudo-random state families generated by a PCG64 generator seeded
  per row; the seed column reproduces the state exactly under the code in this
  repository.
- Wall times were measured on the reference configuration described in the article's
  reproducibility appendix and are not comparable across the two configurations.
- The tables are copied verbatim from the experiment outputs: no column was removed
  or renamed, and no value was altered. They were screened for absolute paths, user
  or machine names, and email addresses, and contained none.
